Trivia Quiz

A full-stack trivia quiz website combining a React frontend with a Node.js backend, user accounts and interactive quiz gameplay.

React Node.js Express JavaScript
01 Overview

Turning trivia into an interactive web experience.

Trivia Quiz is a web application where users can play trivia quizzes through an interactive browser-based experience.

The project combines a React frontend with a Node.js and Express backend, allowing the application to handle users, quiz data and gameplay.

Questions are provided through the Open Trivia Database, creating a varied quiz experience across different categories and difficulties.
