07 Web application · React

Trivia Quiz Website

A full-stack quiz platform where users can play trivia, create their own quizzes and share them with others.

React Node.js Express JavaScript
01 Overview

A quiz platform built from scratch.

Trivia Quiz lets users play quizzes, create their own and share them with others. Questions can also be fetched from the Open Trivia Database.

The project was built as a single-page web application, combining a React frontend with a Node.js and Express backend.

01

Play

Choose a category, difficulty and number of questions to start a quiz.

02

Create

Build your own quizzes with custom questions and answers.

03

Share

Saved quizzes can be shared with others through unique links.

02 Development

Connecting the frontend and backend.

The main challenge was making the different parts of the application work together. React handles the interface, while the Node.js and Express backend handles users, quizzes and data.

User accounts were handled with JWT and bcrypt , while the quiz content was connected to the Open Trivia Database API.
