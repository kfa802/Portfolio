Zombie Game

A 3D zombie game project exploring gameplay, environments, enemies and interactive systems.

Unity C# 3D Game Design
01 Overview

Building a zombie game in 3D.

Zombie Game is a 3D game project focused on creating an interactive environment with enemies, gameplay mechanics and player interaction.

The player navigates through the environment while encountering zombies and interacting with the game world.

The project explores how gameplay systems, environment and enemy behaviour can work together to create an engaging game experience.
