About

I'm a Medialogy student at Aalborg University, which means my work sits somewhere between game design, software engineering, and research methods. I've built serious games evaluated with real playtesters, debugged Unity systems under deadline pressure, and shipped a full-stack web app from login screen to database. I care about whether the thing I build actually works for the person using it — not just whether it compiles.

Selected work

A Learning Game About Women's Suffrage in Denmark

Bachelor thesis · Group project

Designed and built a serious game teaching Danish history through play, working directly with museum and teaching collaborators to ground the content. The project combined Game-Based Learning theory with real evaluation — accessibility passes against WCAG/POUR, playtesting, and statistical analysis (A/B testing, Mann-Whitney U, SUS) to check whether the game actually taught anything.

Plan Bee

Team project — Bee Studios

A 2D beehive colony management game, built with a small team for a game design exam. I worked on core simulation logic, including debugging per-zone egg placement in the nurse-bee system after it broke under a collaborator's edits — the kind of bug that teaches you to actually read the state machine before touching it.
