Trivia Quiz Website.

A full-stack quiz platform where users can play trivia, create their own quizzes and share them with others.

Type
Web application · React
Tools
React · Node.js · Express · JavaScript
01 Overview

A quiz platform built with React and Node.js

Trivia Quiz lets users play quizzes, create their own and share them with others. Questions can also be fetched from the Open Trivia Database, and logged-in users can track their results in a score history.

It was built as a single-page web application for a Web Programming course, combining a React frontend with a Node.js and Express backend.

02 My role

Connecting the frontend and backend

Trivia Quiz was a one-person mini project, so I built everything myself, from the React frontend to the Node.js backend.

The main challenge was making the different parts of the application work together. React handles the interface, while the Node.js and Express backend handles users, quizzes and data. MongoDB was originally planned for storage, but the connection failed, so I switched to JSON files, which work locally but would not scale to many users.

User accounts were handled with JWT and bcrypt, while the quiz content was connected to the Open Trivia Database API.
